# STM32F446RE-Embedded-C-Projects
This repository contains bare-metal Embedded C firmware and peripheral drivers developed for the **STM32F446RE** (32-bit ARM Cortex-M4 Microcontroller). All drivers are written using register-level programming and validated via hardware or simulation testing.

---
## 🛠️ Key Skills & Technologies Demonstrated
* **Programming Language:** Embedded C
* **Microcontroller Architecture:** STMicroelectronics STM32F446RE (32-bit ARM Cortex-M4)
* **IDE & Compiler:** STM32CubeIDE / GCC Toolchain
* **Simulation & Debugging Tools:** Proteus VSM, OpenOCD, ST-LINK
* **Peripherals Interfaced:** 
  * GPIO Configuration (LED, Push Buttons, LCD)
  * Analog-to-Digital Converter (ADC)
  * Universal Asynchronous Receiver-Transmitter (USART/UART)
  * Pulse Width Modulation (PWM) & Timers

---
## Directory Overview
* `01_GPIO_Blink/` - LED blinking and push-button polling routines.
* `02_LCD_Display/` - 16x2 LCD display driver (4-bit / 8-bit mode).
* `03_ADC_Read/` - Multi-channel ADC conversion for sensor interfacing.
* `04_UART_Comm/` - Serial communication driver for PC-MCU data transfer.
* `05_PWM_Control/` - Hardware PWM generation for motor speed control.
